# QuickPaste · 快速粘贴

一款兼顾 **极速、隐私与极致键盘流** 的跨平台全能粘贴工具（支持 **macOS Apple Silicon / Intel** 与 **Windows x64**），基于 Rust + [GPUI Kit](https://github.com/longbridge/gpui-kit) 原生 GPU 渲染打造。

它将**系统剪贴板历史**与**常用片段/备忘录**无缝融为一体：随时随地按下全局快捷键在鼠标所在屏幕唤出，打字秒搜（支持中文全拼、拼音首字母、标签、来源应用与模糊匹配），回车一键粘贴回刚才正在输入的输入框。

---

## 核心特性

### 1. 双模式融合：剪贴板历史 + 常用片段
- **系统剪贴板历史**：后台低开销自动捕获文本、URL 链接、颜色色值、代码片段与 PNG 图片，按 SHA-256 自动去重并保留置顶与使用统计，超限仅淘汰最旧的未置顶条目。
- **常用片段 / 备忘录**：支持应用内新建、编辑、删除、标签分类，同时 **100% 兼容外部 `memos.yaml` 编辑与自动热重载**（`notify` 文件监听 + 启动合并）。
- **一键转存**：任意文本剪贴板记录可一键保存为永久常用片段。

### 2. 富内容智能识别与可视化卡片
- **颜色色值**（`#RGB`、`#RRGGBB`、`rgb()`、`rgba()`、`hsl()`）：自动渲染真实颜色色块，预览页展示 HEX / RGB 转换结果。
- **图片截图**：自动生成高清缩略图与原始 PNG 缓存，支持大图预览并直接粘贴图片到支持的应用中（支持 `⇧Enter` 降级粘贴尺寸描述纯文本）。
- **网址链接**：域名识别，预览页支持一键在默认浏览器中打开。
- **代码与命令行**：自动识别 JSON、SQL、Shell 命令及多行代码并以紧凑代码块样式高亮展示。

### 3. 极致键盘流 + 智能搜索
- **多维度秒搜**：支持多关键词 AND 匹配、中文**全拼**（如 `weixin`）与**拼音首字母**（如 `wxgzh` 匹配“微信公众号”）、标签 `#tag`、来源应用（如 `chrome`、`vscode`）、类型关键词（如 `图片`、`颜色`、`code`）与有序模糊子序列（如 `gpo` 匹配 `git push origin`）。
- **全键盘操作**（无需鼠标）：

| 快捷键 | 说明 |
| --- | --- |
| `⌘⇧V` (macOS) / `Ctrl+Shift+V` (Win) | 全局显示 / 隐藏窗口（冲突自动回退，可在设置中自定义） |
| `↑` / `↓` | 上下移动选中条目，列表自动平滑滚动跟随 |
| `Enter` | 粘贴当前选中条目到刚才的前台窗口（支持配置单击/双击鼠标粘贴） |
| `⇧ + Enter` | 以纯文本形式粘贴 |
| `⌘ + 1~9` (macOS) / `Ctrl + 1~9` (Win) | 直接粘贴前 9 条记录（`+ Shift` 纯文本） |
| `Space`（搜索为空时） / `⌘Y` / `Alt+Space` | 打开 / 关闭全文与大图预览 |
| `Tab` / `⇧ + Tab` | 切换「全部 / 剪贴板 / 常用片段」标签页 |
| `⌘B` / `Ctrl+B` | 置顶 / 取消置顶选中条目 |
| `⌘S` / `Ctrl+S` | 列表页把剪贴板条目存为片段；编辑器内保存片段 |
| `⌘⇧C` / `Ctrl+Shift+C` | 仅复制到系统剪贴板（不自动粘贴） |
| `⌘⌫` / `Ctrl+Del` | 删除选中条目 |
| `⌘N` / `Ctrl+N` | 新建常用片段 |
| `⌘F` / `Ctrl+F` | 聚焦搜索框 |
| `⌘,` / `Ctrl+,` | 打开偏好设置 |
| `Esc` | 清空搜索 → 重置筛选 → 关闭弹层 → 隐藏窗口 |

### 4. 原生系统体验与隐私安全
- **原生常驻**：macOS 菜单栏模板图标（自动适配深浅外观，隐藏 Dock 图标）；Windows 系统托盘图标（左键单击唤起/隐藏，右键菜单控制）。
- **多屏幕跟随**：默认在鼠标指针所在的显示器工作区居中弹出，支持 macOS 全屏空间覆盖显示。
- **粘贴后恢复原剪贴板**（可选）：开启后粘贴完毕自动还原粘贴前的系统剪贴板内容，不污染用户当前剪贴板。
- **强隐私保护**：
  - 自动识别系统隐私剪贴板标记（macOS `ConcealedType` / `TransientType` / `AutoGeneratedType` / 1Password；Windows `ExcludeClipboardContentFromMonitorProcessing` / `CanIncludeInClipboardHistory` / `Clipboard Viewer Ignore`）。
  - 内置常见密码管理器排除规则（1Password、Bitwarden、KeePassXC、macOS 钥匙串/密码等），可在设置页自由增删。
  - 支持一键暂停 / 恢复剪贴板监听。
- **个性化配置**：跟随系统 / 浅色 / 深色主题实时切换、开机自启动（macOS LaunchAgent / Windows 注册表）、失焦自动隐藏、最大历史数量可调。

## macOS 辅助功能权限说明

macOS 出于系统安全策略限制，模拟发送 `⌘V` 自动粘贴需要授予 **辅助功能（Accessibility）** 权限：
- 首次点击或使用自动粘贴时，若未授权，应用会在顶部提示条及「偏好设置」中引导授权；
- 未授权时，选择条目依然会立即写入系统剪贴板，可手动 `⌘V` 粘贴；
- 在「系统设置 → 隐私与安全性 → 辅助功能」勾选 **QuickPaste** 后，即可实现全自动秒贴。

## 数据与配置文件

数据默认保存在系统应用支持目录：
- **macOS**：`~/Library/Application Support/QuickPaste/`
- **Windows**：`%LOCALAPPDATA%\QuickPaste\`

包含文件：
- `config.yaml`：应用配置（热键、主题、触发方式、隐私排除应用等）。
- `history.json` 与 `images/`：剪贴板历史记录与 PNG 原图/缩略图缓存。
- `memos.yaml`：常用片段本地状态；如果启动目录或可执行文件同级存在外部 `memos.yaml` 内容源，程序会自动合并外部内容源的 `text` / `tags` 与本地的 `usage_count` / `is_pinned` / 应用内自定义片段，并监听外部修改实时热重载。

`memos.yaml` 格式示例：

```yaml
memos:
  - title: 工作邮箱
    text: me@example.com
    usage_count: 5
    is_pinned: true
    tags:
      - 工作
      - 常用
  - text: |-
      第一行内容
      第二行内容
    usage_count: 0
    is_pinned: false
    tags: []
```

## 构建与打包

需要 Rust **1.99.1**（`rust-toolchain.toml` 已固定版本）。

### macOS

```bash
# 运行测试与发布构建
cargo test
cargo build --release

# 打包为 QuickPaste.app、.dmg 安装镜像与便携 -app.zip（支持 arm64 / x64 / universal）
./scripts/package-macos.sh --arch arm64 --skip-build
```

产物位于 `target/packages/<target>/`：
- `QuickPaste.app`
- `quick-paste_<版本>_<架构>.dmg`
- `quick-paste_<版本>_<架构>-app.zip`

### Windows

```powershell
cargo test
cargo build --release

# 生成 NSIS 安装包与便携 ZIP（需 cargo-packager 0.11.8）
cargo install cargo-packager --version 0.11.8 --locked
pwsh -File scripts/package.ps1 -Arch x64 -PackageType both -SkipBuild
```

产物位于 `target\packages\x86_64-pc-windows-msvc\`：
- `quick-paste_<版本>_x64-setup.exe`
- `quick-paste_<版本>_x64-portable.zip`
